# Ordis Beta

Installers and automatic updates for **Ordis Beta**, the closed beta of [Ordis](https://ordistrading.com).

This repository holds release files only. It contains no source code.

Ordis Beta is invite only: it asks for an invite key the first time it starts. To join the beta, contact bradleysmith@ordistrading.com.

Download the latest version from [ordistrading.com/beta](https://ordistrading.com/beta) or the [Releases](https://github.com/OrdisTrading/ordis-beta-releases/releases/latest) page.
